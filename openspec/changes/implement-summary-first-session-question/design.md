## Context

用户已授权整个优化规划，要求分段经历整理、总结检索、原文追溯、跨会话分析及明确预算。现有 qa@3 每次完整处理正文；context.ingest.session@2 单请求限15,000字节，经历概览丢失逐项来源。依照 SEM 同日增量、ADR0024；工作树存在其它在途修改，增量保留。

## Goals / Non-Goals

**Goals:** 长会话经历可分页、可复用；相关要点与原文共同召回；结论有来源及历史定位；日期/项目范围局部和全局问题有明确覆盖；失败、取消、撤销及恢复受控；旧绑定与迁移兼容。

**Non-Goals:** 现场音频、永久原始提示、模型内部思维、陪伴型SELF、外部操作、向量/图框架不是本轮前置；不把总结覆盖当语义无遗漏。

## Decisions

版本化输出：`ContextIngestV3` 的 `range` 阶段只含既有 v2 内容，独立范围提交成功后才形成会话经历；宿主以 SQLite 已提交范围生成 `receipt`。`QaAnswerV2` 逐结论保存来源，模型输出 `coverage:null`，宿主填充冻结范围、已访问会话、遗漏与原文/总结覆盖。新版本复用已登记的长输入十轴预算及每次出站配额；局部检索仍按实际调用消费共享预算，不重置预算。原文检索索引属于 SQLite 的可重建派生缓存，缺少 FTS5 时使用有界确定性扫描。

1. storage worker 内新增会话经历范围与逐项经历表，依附既有 episode/source，范围身份绑定源digest、冻结计划及有序事件/code point边界。范围产物和连续整理进度同一事务，重复提交核对digest；取消/失租/越界拒绝。每项保存sourceRef、来源相对时间与必要code point范围；空提取仍记录已消费范围。删会话/经历同步清理，不复制整場字幕。
2. 新摄取@3以确定性容量规划逐范围调用同一Loop，每次输出先校验再提交独立最终范围产物，重试跳过已提交范围。普通纪要/问答中间节点继续零持久化。新版本范围输出与整次覆盖回执分别登记为exact合同，模型不得自定处理进度。confirmed用户信息有界冻结，已有记忆候选与关联处理复用事务逻辑。
3. 检索动作由个人上下文模块拥有，静态exact参数包含授权范围、冻结输入身份、宿主生成的词法关键词及字节/条数上限。中文短词与日期数字有精确路径；三字以上可用FTS5 trigram。原始正文只读首次final锚点；索引可重建，失效内容不可读。纪要概要只用于定位，引用条目可形成候选，不据概要捏造细粒度依据。
4. 新qa@4接收宿主组织的有界经历/纪要/原文证据，输出逐结论来源及覆盖说明。后续工具仍是冻结记忆别名工具，工具集不动态扩大。每次外发容量、HTTP、输出、请求数、累计用量/时限沿版本化预算核验，终态之前复核源与授权，失效或取消零最终答案。
5. 日期/项目范围由现有范围解析器扩展并冻结会话目录，UI/main/preload使用版本化exact合同。具体事项联合检索；全局主题分页读取有效经历及纪要并分批归并；枚举/计数扫描完整冻结来源，缺口显式呈现。所有批次共享绑定及预算，不自动补处理全部旧历史。
6. 来源沿既有context-source导航零模型打开，结果逐断言按钮显示日期/相对位置，跨页定位对应版本/事件，失败保留当前结果。来源定位使用首次稳定转写的时间排序，随定位返回最多50个属于事件范围的字幕段ID，历史页对命中的可见段显示“引用段落”和焦点轮廓；不扩展既有历史正文DTO。普通纪要不生成个人事实；候选批次冻结ID/revision、CAS事务仅消费冻结集合，期间新增候选留待下一批。现有context.synthesize与确认/撤销治理继续复用。

## Risks / Trade-offs

候选整理新增 `context.synthesize@2`，输出沿用现有综合视图合同。批次冻结 batch ID、起始revision及候选的逐条memory/revision身份，消费回执与投影同一事务；消费只记录已整理身份，不删除或确认底层候选。无关新写入不使批次失效，冻结条目被改动、撤销则拒绝提交。新候选仍待下一批，旧@1继续按全局revision检查。进行中的事项只从有效明确todo派生：原文明示且有效的完整日期按主机本地日历用于时效过滤，没有有效日期时显示截止时间未确认，不推测履行状态。

- 摘要遗漏→独立原文召回及否定/修订内容评估；中文短词漏召回→专用合成用例。
- 范围产物被误认为临时缓存→exact产品合同、来源身份和原子覆盖回执；整场结果仍原子发布。
- 长存储读取阻塞字幕→keyset分页、预算及取消检查点，模型在事务外运行。
- 来源或个人信息撤销竞态→提交前双侧身份/revision复核，索引和投影即时不可读。

## Migration Plan

范围接口沿既有 exact `scope.kind/reference`，日期引用编码为 `date.<fromMs>.<throughMs>`（左闭右开，UI转换本地日期），项目引用只接受已登记的 scope ID，显示同名项目的ID。新增目录与证据页 migration，不修改25/26；目录逐页冻结到SQLite，覆盖所有符合条件的已结束会话。局部问题检索，全局问题读取全部有效要点，枚举/否定问题读取全部来源；超出冻结来源或节点预算明确拒绝。分批模型结果只在内存归并，证据页只保存ID、边界及digest。日期/项目暂用空的受控记忆工具上下文，经历检索仍遵守记忆许可；不把未冻结的个人条目临时注入模型。

按当前最新schema追加版本，不改已有SQL/checksum。先注册新recipe/合同，接通经历存储与摄取，再切换新建问答入口，最后扩日期/项目和全局分析。旧绑定/结果/导出解释器保留。回退仅停止创建新版本，不删除用户产物或回写旧迁移。
