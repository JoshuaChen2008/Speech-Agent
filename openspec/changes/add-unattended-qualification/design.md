## Context

I2 五轮序列和 I3 75 秒资格已有独立 runner、严格 verifier 与隐私边界，但需要人工选择和串行执行。更关键的是，现有 runner 只解析权威识别器，未把临时字幕识别器传入 `RealtimeRuntimeAdapter`，因此旧报告不能证明 SEM-F21 的同源两阶段实时识别路径。

## Goals / Non-Goals

**Goals:**

- 使用生产模型 resolver 和真实运行时接线验证两阶段识别。
- 用单一命令无人值守执行预检、非音频检查、75 秒资格和五轮延迟序列。
- 产生可严格复核、能区分阻断类型且符合 SEM-F14 的汇总。
- 失败后有界收束，不要求用户接管进行补救。

**Non-Goals:**

- 不替代物理麦克风、设备移除、睡眠/唤醒、真人鼠标、两小时长稳或干净机发布验收。
- 不自动下载模型、修改系统配置、创建虚拟机或重试失败序列。
- 不改变冻结字幕可见延迟的起点、终点、阈值或五轮规则。

## Decisions

- **共享显式模型根。** I2/I3 与无人值守编排均接收 `--model-user-data`，并以 `allowExternal:false` 解析四项需要的资源。这样结果不受环境变量或开发目录偶然存在影响。
- **报告版本前进。** I2 child/series 和 I3 资格报告增加两阶段模型身份与临时字幕识别器运行事实。严格 verifier 继续读取历史 schema，但新编排只接受新 schema，避免旧证据冒充新路径。
- **串行阶段状态机。** 编排按 `preflight → deterministic → i3-qualification → i2-series` 顺序运行。阶段只产生 `pass`、`blocked`、`failed`、`skipped`；失败跳过依赖阶段，独立检查继续。
- **稳定失败分类。** 环境/资源缺失使用受控阻断码，产品断言与 evidence 校验使用独立失败码；异常原文和绝对路径不写汇总。
- **新鲜输出。** 输出目录必须位于工作区且不存在，防止混入旧报告；每轮 child 继续由外部 runner 写 exact exit sidecar。

## Risks / Trade-offs

- [Risk] 当前机器没有完整四资源模型，无法运行音频阶段。→ 形成 `blocked` 汇总并完成独立非音频检查，不自动改变环境。
- [Risk] Electron/GPU 环境在产品断言前退出。→ 归类为执行环境阻断，不记为产品通过或失败。
- [Risk] 自动播放干扰用户当前音频。→ 入口文档明确播放受控语料，音频阶段串行且整体有界；本轮用户已授权执行。
- [Risk] schema 升级使历史报告失效。→ verifier 按版本兼容读取，只有新编排拒绝历史 schema。
