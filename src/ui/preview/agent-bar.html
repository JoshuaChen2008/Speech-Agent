Agent Bar 视觉设计基准

状态、文案与信息架构逐条取自 docs/agent-ui-ux-handoff.md §13.3 / §13.4。 控件外观直接引用 src/settings/settings.css，与设置页 · Agent 模型配置档案同源。

这是设计基准，不是产品实现：页面不进入生产 bundle，不经过任何 exact validator， 不构成 J22/J24 证据，也不表示正式 agent renderer 的前置 contract 已冻结 （AUI-CR-010–019 仍为 open）。这里的数据是手写设计取值，不是后端事实。

「去掉颜色」用来核对同一条规则：颜色只是冗余通道。勾选后每个状态仍必须靠文字与形状区分。 页面本身是预览外壳，只有卡片里的 Agent Bar 才是设计基准。
