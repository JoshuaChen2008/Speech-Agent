# Speech-Agent

一个 Windows 11 桌面字幕工具，带一个按需开启的 AI 助手。

开会、看课程，或者对着麦克风说话时，把内容转成屏幕上的字幕。听的时候看字幕，之后查记录；需要整理内容时，再让助手做会话总结、回答问题。

字幕独立运行。助手的结果另存，字幕原文保留。

## 目前的功能

- **实时字幕**：选择系统音频或麦克风音频，支持暂停、继续和停止。字幕窗可以拖动、调字号和透明度，锁定后鼠标点击穿透。
- **字幕记录**：按时间查看，导出为 TXT、Markdown 或 SRT。默认读取字幕原文，精修稿单独保存，可以切换查看。
- **字幕助手**：选定会话或日期范围，对已保存字幕做总结和问答。生成记录可以回看，运行中可以取消。
- **我的记忆**：由你确认哪些项目事实、决定、待办或偏好值得长期保留。新记忆以 Markdown 文件保存，目录由你选择；在外部改过内容后，重新确认才会被助手引用。
- **记忆导出与共享**：选中已确认的记忆，预览后复制或导出 Markdown / JSON；也有按条授权的本机只读 MCP 接口。操作见[个人记忆指南](docs/personal-memory-guide.md)。

一场会话只用一种音频来源。要换来源，先停止，再开始新会话。

## 从源码启动

需要 **Windows 11 x64、Node.js 22.x 和 npm**。原生模块构建还需要 Python 3 和 Visual Studio C++ 构建工具（选择“使用 C++ 的桌面开发”）。

在项目目录打开 PowerShell，执行：

```powershell
npm ci
npm run electron:install
npm start
```

`npm start` 会先构建界面和两个原生模块，再启动应用。

第一次使用：

1. 打开设置的“模型资源”，下载字幕必需模型：实时预览模型、字幕识别模型和语音检测模型。首次下载需要联网，模型就绪后本地识别可以离线运行。
2. 选择系统音频或麦克风音频，开始字幕。锁定快捷键默认是 `Ctrl+Alt+L`，可以在设置的“快捷键”中修改或关闭，也可以用工具条按钮锁定。
3. 需要总结或问答时，在“助手模型”中配置 OpenAI 兼容服务，并启用 AI 助手。个人记忆按需启用，内容在“我的记忆”中管理。

精修默认关闭，需要另外下载精修模型。修改精修开关只对之后新开的会话生效。云端识别目前接入阿里云 NLS，启用前需要配置服务信息，并明确允许发送音频。

## 数据怎么保存

字幕记录保存在本机 SQLite 中。原文与精修稿分开，助手生成的内容也不会覆盖原文。新建个人记忆的正文保存在 Markdown 文件里，来源、确认和撤销记录保存在 SQLite；原有数据库记忆可以在设置中手动移到文件。

应用不保存现场音频，识别所需的临时内存缓冲用后释放。

选择云端识别会发送音频；调用云端助手模型会发送本次请求所需的文字。记忆的云端语义搜索默认关闭，启用时需要单独允许向服务商发送已确认的记忆正文和查询。这几种数据用途分别说明、分别授权。

## 开发与验证

改代码前先读 [AGENTS.md](AGENTS.md) 和 [CONTEXT.md](CONTEXT.md)。功能边界以[语义合同](docs/semantic-contract.md)为准，验证范围以[测试策略](docs/testing-strategy.md)为准。

```powershell
npm run verify:renderer   # 界面类型检查与生产构建
npm run test:focus -- test/ui/renderer-style-guard.test.js  # 定向示例
npm test                  # 构建一次，依次执行 core / integration / evidence
npm run package:release   # 构建 Windows x64 安装器
```

定向验证按改动范围选择；合并与阶段联合验收需要当前修订的完整回归。自动化结果不能替代真实音频、窗口交互和干净机验收。

安装器输出在 `.artifacts/release-package/`，模型不随安装器打包。当前安装器尚未签名，发布验收范围见上面的验收导航。
