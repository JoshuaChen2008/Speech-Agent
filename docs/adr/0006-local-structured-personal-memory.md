# ADR 0006：个人记忆使用本地 SQLite 结构化事实与投影

- 状态：已决定
- 日期：2026-08-09
- 决策者：项目负责人
- 依赖：ADR 0001、ADR 0002、ADR 0003

## 背景

Agent 需要从会后正文沉淀用户经历的项目轨迹、决定、待办、术语和偏好，以改进后续摘要、聊天和识别关键词。直接保存整场正文副本会制造第二权威，把所有内容无差别写入又会迅速积累噪声；引入图数据库或向量数据库则增加部署、同步、隐私和迁移成本，首版没有足够收益。

## 决策

1. 个人记忆偏好默认开启，但只有 Agent 总开关与个人记忆同时生效、Agent 处理资格为 `ready`，且会话不早于当前个人记忆自动处理边界时，终态会话才进入静默筛选；“全量”指该边界内会话的全覆盖筛选，不指复制全部正文。
2. 个人记忆与 Agent 产物使用现有单个 SQLite 和 storage worker，不创建第二个数据库、JSONL 事实源、图数据库或向量数据库。
3. 权威原始转写仍是唯一完整正文。记忆保存原子结构、追加证据、来源事件范围、水位、digest 和当前投影；合并、冲突或替代不得无痕改写来源历史。
4. 筛选分为长期结构化记忆、会话经历记录和丢弃。明确决定、结论和待办不要求重复出现；寒暄、填充、明显识别噪声和无来源推断直接丢弃。
5. 明确偏好与推断倾向分开。冻结字幕快照没有说话人身份时，`memory-extraction` 返回的全局个人偏好候选无论自报 `explicit` 还是 `automatic` 都不能入库；会话表达最多形成会话/项目倾向候选。全局偏好只能来自独立的用户明确确认动作，且用户确认内容只能由用户再次明确修改。
6. 首版检索只使用结构化范围、类型、规范化关键词和别名匹配，不启用 FTS5、embedding、`sqlite-vec`、图查询或自动语义聚类。
7. 自动记忆可以在有界范围内辅助 Agent；只有用户确认的术语、实体名和别名可以进入后续会话的 ASR 关键词快照。写作与摘要偏好只影响 Agent 产物。
8. 全局关闭个人记忆会同时停止新提取、检索注入和未来新会话中由个人记忆产生的确认关键词；现有记忆留在本地休眠。个人记忆每次从不生效转为生效时形成新的个人记忆自动处理边界，自动对账不得补处理关闭期间或更早的会话；用户仍可在个人记忆开启且当前 Agent 处理资格为 `ready` 时明确请求重新提取。删除单条个人记忆时，由 storage worker 在一个幂等事务中为每个既有来源 digest 写入不含原条目内容的 suppression，再物理移除当前条目、revision 与 evidence，避免相同旧输入静默恢复。
9. 本地或云端 Agent 模型 provider 都可以执行提取，但产品持久化始终在本地。首版不提供逐会话敏感标记；选择云端 Agent 模型 provider 前必须明确告知终态会话正文会发送给该服务。
10. 纪要、增强文本和记忆提取是并列后台任务，直接读取同一输入快照；记忆不得从摘要二次提取。

## 取舍

- 相比向量或图记忆，结构化 SQLite 的语义召回能力较弱，但来源、迁移、删除和确定性测试更清晰。
- 相比只记录用户显式动作，静默筛选能保留真实项目轨迹；代价是必须严格区分推断倾向、明确偏好和说话人未知。
- 相比原地更新一张记忆表，追加证据与当前投影占用更多行，但能解释一条记忆为何存在、何时失效。

## 未选择

- 把完整权威原始转写复制到记忆表。
- 首版引入独立图数据库、向量数据库、FTS5 或 embedding。
- 未经确认的自动关键词直接影响 ASR。
- 关闭个人记忆时自动删除字幕历史或全部记忆。
