# ADR 0024：总结检索优先问答与范围会话经历记录

状态：已决定；2026-10-01。依据用户授权的总体规划，修订 ADR 0009/0021/0023 对新版本问答及会话经历摄取的输入政策，保留旧运行解释。

新会话经历摄取按确定性来源范围形成独立最终产品记录，事务提交经历、来源和整理进度；它不属于 Loop 临时输出缓存。新问答先通过个人上下文模块检索有效经历和纪要，并让权威原始转写独立参与召回，再读取有界相邻证据。全局回顾分页遍历冻结范围，完整枚举与计数采用完整来源策略，不能由局部检索推断。

选择范围产品是为了重复利用一次整理成果，同时保存逐项来源，代价是新增覆盖、失效及删除治理。旧整场纪要/问答仍只发布完整最终结果，临时正文和模型中间文本仍仅内存。各范围的最终经历不是整场纪要，也不能冒称整场语义无遗漏。

复用 SQLite 单写者、个人上下文 ingest/resolve/manage、同一 Agent Loop、模型绑定及预算账本；词法检索由模块拥有，不扩张既有 search_context@1 别名等值工具。候选确认、个人记忆休眠/撤销和正式提示清理规则继续成立。关联 SEM-F26/F28/F30/F31/F34/F39/F40、J21/J22/J24/J29/J30/J31、DB1/DB7/J10/J12。
