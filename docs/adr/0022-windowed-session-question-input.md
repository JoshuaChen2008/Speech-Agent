# ADR 0022：新会话问答使用版本化模型窗口预检

- 状态：已决定
- 日期：2026-09-30
- 关联：SEM-F16/F28/F31/F33/F40、J22/J24/J30、DB1

旧 `qa.answer@1` 把完整会话拼入 prompt，再按15,000 UTF-8字节拒绝；Loop与adapter另有旧限制。总结扩容仅针对 `summary.minutes@2`，因此共享执行宿主并不使问答自动获得新的容量。

新建用户问答使用 `qa.answer@2`，沿用原输出结构、默认模型用途、静态轮次与工具授权。输入窗口、输出额度和每次外发的序列化输入保护由 budget-axes 根据不可变模型运行绑定统一派生；总结的既有派生函数保持兼容入口和原数值。旧运行不升级版本、不改写绑定。

本步只处理单个模型窗口内的完整输入，保留问答60秒与旧累计/工具预算。超窗口输入明确拒绝，不依赖纪要、不截断；分块问答属于第二步。未知tokenizer以UTF-8字节作保守输入单位，未知provider用量仍为null。

专用 `AGENT_QA_INPUT_LIMIT_EXCEEDED` 与字节诊断证明问答生成模型尚未调用；意图收敛模型的调用事实独立。v21仅追加两个 `qa_input_limit_error` 布尔字段，避开旧表冻结的错误码CHECK；v1–v20迁移不改写，公开读取恢复专用码。UI与诊断不保存正文或路径。
