# ADR 0025：个人记忆文件正文与可重建统一检索

- 状态：已决定
- 日期：2026-10-02
- 依据：SEM-F41/F42，J21/J28-FILES、J22/J24-RETRIEVAL、DB1/DB7/J12
- 部分替代：ADR0006 的个人记忆正文位置与仅等值召回；ADR0001 的字幕权威和单写者、ADR0002/0017 的字幕独立性继续有效。

已确认个人记忆可经用户迁移到自选目录中的 Markdown；SQLite 保留治理事实。记忆候选与会话经历记录不迁移。文件中确认/来源声明没有授权效力；外部正文、kind、scope 改变需再次确认。稳定 ID 与路径分离，文件不可读时不使用旧正文。

直接编辑使用独立、按需加载的 N-API Win32 文件模块，OPEN_EXISTING + shareMode=0，同一句柄核验/写入/FlushFileBuffers。独占创建用于新文件；不以 hash→rename 冒充比较交换。恢复材料限于受控操作目录，不写日志、报告或SQLite正文；跨介质准备记录只含身份、摘要、阶段、幂等键。目标摘要匹配则收束，旧摘要匹配则取消，其它内容须明确处理。

表征模型配置单独管理连接和凭据，不占用四个推理用途。云端表征默认关闭、单独披露正文与查询外发；只支持受信任HTTPS的OpenAI-compatible /embeddings。它是可取消派生索引工作，不是第二条固定recipe执行路径。关键词FTS5及Float32向量均为本地SQLite派生索引，RRF融合；不引入远端向量数据库。关联仍等值核验，不使用相关性证明本人归属。

正文迁移逐条切换，未迁移条目沿旧路径；已切换条目旧正文清理且禁止回读。治理携带只含摘要/来源引用/撤销，不恢复未验证确认。重建索引不改变治理事实。文件、网络、索引及原生模块失败不改变字幕事务或字幕启动条件。
