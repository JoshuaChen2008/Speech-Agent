# ADR 0023：会话问答复用确定性完整输入计划

状态：已决定

关联：SEM-F16/F28/F31/F33/F35/F39/F40、J22/J24/J30/J31/DB1，补充ADR 0009/0016/0021/0022。

第一步qa.answer@2只容纳一个模型窗口，长问题仍无法执行。新建raw单会话问题使用qa.answer@3，固定qa-long-input@1；其它范围保留@2，旧绑定不可变。recipe版本已足以冻结新策略，不增加策略列或修改任何已存在迁移。使用现有Agent输入计划、run预算、attempt预算及模型请求回执表记录无正文的计划身份和累计用量。

共享总结的确定性分页、Unicode分块、连续来源归并和取消边界，但每个问答节点仍执行qa.answer并返回QaAnswerV1。叶节点只回答原问题在本块中的证据，信息不足明确留待归并；归并携带原问题、按来源顺序保留否定和后文修订，不能把部分证据声称为整场事实。中间结果≤8 KiB，全部来源核验后才提交一个最终回答，不持久化原问题、分块正文或中间输出。

容量、十轴作用域、调用及时间上限参照语义合同第二步登记：完整输入4 MiB/8 MiB/50,000段，256叶/384节点/512请求，每Loop180秒、attempt60分钟、run120分钟/2attempt，累计provider输入16,000,000与输出1,000,000 token。工具预算由所有节点共用。未知provider用量维持null，规划估算不得伪装成实际用量。单请求输出目标8,192、模型窗口与字节保护沿第一步。

自由问题无法在应用重启后重建原提示，继续沿既有固定会话范围重新输入/新请求事务，不默认为可续跑。导出版本4只作用于新问答策略，携带question_input_policy/question_input_plan；旧编码器与旧预算数值不改写。代价是长问答需要多次模型调用和更长等待，取消或失败不能返回貌似完整的部分回答。
