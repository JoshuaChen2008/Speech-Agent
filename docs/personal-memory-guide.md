# 个人记忆文件与检索

## 内容导出与只读 MCP

状态：实现完成·尚未验收（SEM-F43/F44、J28-EXPORT/MCP）。[验证范围](validation/personal-memory-sharing-2026-10-03.md)。

在设置的个人记忆页面展开“导出记忆与只读 MCP”。开启 AI 助手和个人记忆后，点击“读取可选记忆”，按范围筛选并勾选最多20条，点击“预览选中内容”。随后选择 Markdown 或 JSON，复制或导出正文、类型、范围、修订与来源身份。单次内容上限64 KiB，超限请减少选择；候选、未确认修改及撤销内容不可导出。

同一预览下点击“授权选中内容并开启 MCP”，再“复制 MCP 连接配置”。将配置交给支持 Streamable HTTP 和 Authorization 请求头的本机 MCP 客户端（具体导入位置由客户端决定）。配置包含临时访问令牌，仅提供给信任的客户端。服务只监听127.0.0.1随机端口，支持 `list_memories`、`read_memory`、`search_memories`；关键词查询不调用模型，也不会读取未选中的内容。

“停止共享”、暂停个人记忆、关闭 AI 助手或退出应用会撤销本次连接；重启后默认关闭。内容变化后须重新预览、授权并复制新配置。外部已保存的副本不随撤销删除。每次授权最多8个 MCP 会话，单请求8 KiB，单并发读取；客户端遇到授权失效应返回应用重新授权。本次不包含会话背景批量导出。

依据 SEM-F41/F42、ADR0025、J21/J28-FILES/J22/J24-RETRIEVAL。实现状态与验证范围见[交付记录](validation/personal-memory-files-2026-10-02.md)。

设置 → 个人上下文 → 我的记忆 → 记忆文件与检索。新记忆以 Markdown 保存；原有已确认条目继续沿 SQLite 路径，只有勾选并点击“将选中记忆移到文件”才逐条切换。候选与会话经历记录不自动迁移。

“选择记忆目录”经系统对话框指定一个目录，默认使用应用数据目录中的 `personal-memory/notes`。可以关闭“允许应用写入此目录”，继续外部编辑、查看和引用已经确认的当前内容。只读目录中的无元数据文件需先自行补充下述字段，应用才能在不写入文件时确认。

一份文件一条记忆，UTF-8，正文最多2048字节、整个文件最多64 KiB。文件名与子目录可以改，`id` 必须保持稳定且唯一。示例：

```md
---
id: memory.example
kind: project_fact
scope: {kind: global, reference: null}
---
项目使用 SQLite 保存来源与撤销记录。
```

`kind` 支持 decision、conclusion、todo、term、preference、project_fact、experience。`scope` 支持 global/session/topic/project，非全局范围须使用已登记的会话或范围身份。未知 YAML 字段、注释和既有排版保留。没有元数据的正文可预览，并在确认面板选择类型与范围；应用写入元数据仍受写入许可约束。

外部修改正文、类型或范围后，该条目立即退出 Agent 引用。刷新并点击“核对并确认”，检查当前内容后确认此修订。只改文件名、注释或未知元数据不会增加来源或取消有效确认。重复 ID、格式损坏、目录失联均暂停相关读取，不回读旧数据库正文。普通总结和外部保存不会自动确认个人记忆。

应用内“修改”仍可直接保存。竞争或错误时保留草稿；原生文件锁组件缺失则暂停写入和确认。迁移中断后可再次选择原条目，空占位文件经独占核对后重试，其它已有内容会报冲突。忘记撤销引用并保留文件；删除先提交撤销，再按原字节摘要清理文件。设置页显示待清理状态，可重试；文件内容已变化时不会覆盖或删除。被撤销文件从备份重现仍需明确恢复确认。

“云端表征模型”默认关闭。填写 HTTPS 服务、基础路径、模型 ID，单独确认已确认记忆正文及查询的外发范围，保存独立凭据，再启用。不会复用四个推理用途的密钥或披露。仅在 Agent 和个人记忆开启时运行自动索引；候选、未确认修订、字幕正文、被忘记或删除的条目不会送入表征。云端错误或查询超过3秒时显式降级关键词。关闭会取消请求并拒绝迟到写入。

设置页搜索提供关键词管理；正式新问答 `qa.answer@5` 使用统一关键词与向量检索，旧运行继续原版本解释。索引可取消、重建；重建只影响派生数据，来源和撤销记录保持不变。总结参考关闭时不会读取个人记忆文件。

换设备时复制整个记忆目录，再明确导出/导入来源与撤销记录。该版本化 JSON 不含正文、凭据或绝对路径；不自动确认外来文件，缺失来源标为缺失，不伪造来源可访问性。旧 SQLite 完整备份仍需与版本匹配，不能用旧应用直接编辑已切换条目。

开发运行：`npm start` 会构建 renderer 和两个原生模块；Windows 原生构建需要现有 node-gyp/VS C++ 工具链。打包 prepared 命令会核对字幕窗口与记忆文件两个原生模块，记忆模块通过 ASAR unpack 加载。文件、索引或云端失败不影响字幕独立链路。
