# 字幕窗锁定快捷键设计

2026-10-04；已决定。要求以 [SEM-F22/F23 与 SEM-T04](semantic-contract.md) 的同日登记为准，旅程为 [J17-SHORTCUT](testing-strategy.md)。术语见 [CONTEXT.md](../CONTEXT.md)，官方设计与平台依据见[调研](research/caption-unlock-shortcut.md)。

设置新增“快捷键”类别。用户先看到启用开关、当前键位和用途，再看到“录入按键”与“恢复默认”。默认保留 Ctrl+Alt+L 按一次切换字幕窗锁定，开关关闭时保留已保存键位。恢复默认明确恢复键位并启用；注册或保存失败保持原配置。

点击录入后暂停本功能，焦点进入只读按键录入框。实际按键形成草稿，全部松开后才允许保存；左右 Ctrl、Alt、Shift 明确显示，右 Alt 可单独保存。用户可再次按键替换草稿，Tab 到达保存/取消按钮，Esc 取消；保存、取消后焦点返回录入按钮。失焦、离开类别、关闭和 reload 撤销草稿并恢复；旧异步响应不重新打开录入。当前键位在保存之前保持原值，失败反馈留在录入项附近。

普通键组合在按下时切换一次，纯修饰键在全部松开时切换一次。按住修饰键期间夹带其它键或鼠标按钮会取消这次触发，避免 AltGr 输入字符或 Alt 配合鼠标操作误触。录入与保存结束后，主进程先观察全部释放再接受新输入。字幕窗提示由实际生效状态生成；关闭或暂时无法启用时，引导用户点击工具条锁定按钮。

启用状态和键位分别通过现有 ConfigStore 原子保存。旧配置补默认，损坏的显式键位关闭本功能且保留其它偏好；配置数组归模块所有，不允许调用者后改。main 拥有全局注册、重复抑制、录入暂停及原生观察生命周期，preload 只接受 settings 的严格布尔录入请求。系统注册与原生读取是外部边界；设置、配置、控制器和锁定广播都保持真实实现。

通用修饰键组合与普通单键沿用 Electron 系统注册；左右专用组合和纯修饰键使用既有 caption-input 扩展读取 Windows 当前高位键态，并以 16ms 有界轮询维护一次按下/释放的内存状态。该观察不证明其它应用没有相同绑定，也不拦截它们的原有键功能。安全桌面、UIPI、真实布局和物理短按仍须实机观察；轮询与确定性注入不构成 I2 验收证据。键态不写入配置、日志、数据库或报告；配置只保存用户明确选择的键位。
