## 更新约定

**仅在用户明确要求时更新。** 代码改动、应用启动、提交或其他任务都不触发截图更新；本档案没有自动化任务。

下次明确要求更新时，使用独立应用数据目录，按实际页面与状态采集；创建新的日期目录（同日加递增后缀），保留旧快照，再更新最新浏览页与本说明。每张图记录入口、状态、截图尺寸与原图 SHA-256。无法进入或尚未覆盖的状态必须明确记录，不能用原型或旧截图代替当前界面。

## 本次范围

第二组覆盖字幕助手初始界面、范围问答、跨会话分析、项目空状态，以及浅色与 520px 窄窗口。01–04 为布局修订构建，05–06 同时包含主题同步修复；两次布局 CSS 相同。此前第一组覆盖首次设置、七个设置分类、工具条、字幕窗和字幕记录。内容详情、真实运行过程、系统高对比及其他系统 DPI 尚未覆盖。

保持 JPEG 原始字节；不裁切、拼接或美化。字幕助手持续显示的“正在读取…”仍为既有缺口；第一组中的控件拥挤和标题栏折行由第二组展示修订。参考 [规范术语](../../CONTEXT.md)、[语义合同](../semantic-contract.md)（SEM-F14/F23/T01/T02/T03）与 [旅程矩阵](../testing-strategy.md)（J18/J22/J29）；本档案只供设计评审参考，不作为这些旅程的验收证据。
